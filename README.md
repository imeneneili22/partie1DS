# Gestion des tâches (Python)

Petite application console en Python pour gérer des tâches quotidiennes.
Projet réalisé en binôme dans le cadre du module « Outils collaboratifs avec Git / GitHub » (Licence 1).

**Auteurs :** NOM1 Prénom1 et NOM2 Prénom2

## Fonctionnalités

- **1 – Ajouter une tâche** : saisie d'un titre (un titre vide est refusé).
- **2 – Afficher les tâches** : liste numérotée, ou message si la liste est vide.
- **3 – Rechercher une tâche** : affiche les tâches dont le titre contient un mot-clé.
- **0 – Quitter** : ferme le programme. Toute autre option affiche un message d'erreur.

## Étapes réalisées

1. Création du programme `main.py` avec le menu, l'ajout et l'affichage.
2. Rédaction de ce `README.md`.
3. Ajout de la recherche de tâches.
4. Publication du dépôt sur GitHub, puis mise à jour publiée avec `git push`.

## Exécution

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **« Run Python File »** (triangle en haut à droite de l'éditeur).
4. Utiliser le menu dans le terminal intégré.
